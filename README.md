# Guild Ledger Forever

Standalone guild roster, crafting directory and shared loot feed for WoW Forever (Camelot).

- [Download on CurseForge](https://www.curseforge.com/wow/addons/guild-ledger-forever)
- [Installation, features and privacy](GuildLedger/README.md)
- [Changelog](GuildLedger/CHANGELOG.md)
- [Bundled library notices](GuildLedger/Libs/THIRD_PARTY.txt)

The `GuildLedger/` directory contains the complete addon source and embedded dependencies from release 0.4.0. Copy that directory into your client's `Interface/AddOns/` directory to install from source. No separate libraries are required.

## Bug reports

Use GitHub Issues to report problems. Include the addon version, client build, steps to reproduce and any relevant Lua error. Review diagnostics before posting: they can include character names. Do not upload SavedVariables, private guild information, credentials or private Discord invites.

This repository contains release source and documentation only. Personal configuration, live guild data, local backups and development screenshots are not included.
